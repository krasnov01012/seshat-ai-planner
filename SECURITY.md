# Security policy

## Секреты

Не добавляйте в Git реальные значения `TELEGRAM_BOT_TOKEN`, `NVIDIA_API_KEY`,
`API_TOKEN`, `POSTGRES_PASSWORD` или OAuth credentials. Используйте локальный
`.env`; в репозитории остаётся только пустой `.env.example`.

Если секрет попал в commit, одного удаления строки недостаточно: сначала отзовите
и перевыпустите credential, затем очистите достижимую историю до публикации.

## Развёртывание

Пример Compose предназначен для локального запуска. Перед внешней публикацией нужны
отдельный ingress, TLS, rate limiting, резервное копирование и ограниченный доступ
к диагностическим endpoints. Не публикуйте PostgreSQL или внутренний API напрямую.

## Сообщение об уязвимости

Не создавайте публичный issue с рабочим токеном, персональными данными или способом
доступа к живой системе. Сначала отзовите затронутый credential и свяжитесь с
владельцем репозитория через профиль GitHub.
