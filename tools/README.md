# tools — скрипты замеров

Скрипты, которыми получены цифры из [../docs/AI_MODELS.md](../docs/AI_MODELS.md).
Зависимостей нет, только стандартная библиотека Python.

Ключ передаётся **путём к файлу**, а не значением, — чтобы не попадал
в историю команд:

```bash
NVKEY=/path/to/nvidia_key.txt python tools/bench_nvidia_ru.py
```

| Скрипт | Что делает |
|---|---|
| `bench_nvidia_ru.py` | Точность разбора 10 русских фраз планировщика по полям. Пишет `bench_results.json` с сырыми ответами (файл в `.gitignore`) |
| `bench_structured.py` | Поддержка `json_schema`, `json_object` и `nvext.guided_json` у моделей-финалистов |
| `stress_nvidia_limits.py` | Реальные лимиты бесплатного тарифа: различает `429` (лимит ключа) и `503`/`529` (нехватка мощностей провайдера) |

Прогонять `bench_nvidia_ru.py` при каждой смене основной модели и при заметном
росте числа переспросов у бота. На фазе 2.5.6 второго роадмапа он становится
регрессионным тестом.

Набор фраз в `CASES` — это же приёмочный набор для этапа 2 первого роадмапа.
Дополнять его формулировками, на которых бот ошибся в реальной эксплуатации.
